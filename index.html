Projects

x3d-mcp

x3d-mcp is an open-source Model Context Protocol (MCP) server that lets large language models generate, validate, edit, and animate ISO-standard X3D 3D scenes. It bridges LLMs' spatial reasoning with a declarative, interoperable 3D format, with multi-layer validation against the X3D specification. The project was merged into the Web3D Consortium's official x3d_mcp repository, contributing the semantic validation layer, animation tooling (TimeSensor + Interpolator + ROUTE chain generation), scene CRUD operations, X3DOM rendering, and guided MCP prompts, developed in coordination with the AI with X3D Working Group.

Technology: Python, FastMCP (official MCP SDK), lxml for XSD and Schematron validation, and the Web3D Consortium's x3d.py package, with Docker-based testing.

Official Repo Reference Implementation

X3Test

X3Test is an open-source npm library for automated, headless performance benchmarking of X3D/X3DOM web scenes. Built on Node.js and Puppeteer, it measures FPS, render time, and scene node counts through both a CLI and a JavaScript API, making it easy to drop into CI/CD pipelines for regression testing of 3D web content. X3Test won 3rd Place in the Tool/Pipeline Innovation of the Year category at the Web3D '25 Tools Competition and is published as a peer-reviewed paper at ACM Web3D '25, the 30th International Conference on 3D Web Technology.

Technology: Node.js, Puppeteer for headless browser automation, published on npm, designed for CI/CD integration.

Source Code Paper

Rural STARS

Rural STARS is a survey analysis platform built for Virginia Tech's Center for Rural Education to identify gifted students in rural school districts. QuestionPro webhooks feed survey responses into the platform in real time, where Likert data is normalized and candidates are flagged via per-scale thresholds across five talent domains, with cross-scale aggregation to surface multi-talented students. A validation and reporting pipeline generates branded per-school PDF reports with TLS-secured email delivery - replacing what was previously a fully manual spreadsheet-and-calculator evaluation process for county personnel.

Technology: Python, Streamlit, Pandas, NumPy, ReportLab for PDF generation, and SMTP with TLS for secure report delivery.

TL;DW

Too Long; Didn't Watch (TL;DW) is an innovative application designed to address the challenges of information overload and shortening attention spans in the digital era. TL;DW enables users to interact with and quickly comprehend the essence of lengthy video content. The technology behind TL;DW integrates large language models (LLMs) and video encoders to create a natural, conversational interface for video analysis. Key features include on-demand video summarization, keyword-based prompt recommendations, and navigation to specific video segments guided by AI-generated responses.

Technology and Datasets: The application is built using Streamlit and incorporates Langchain components such as FAISS ChatOpenAI and OpenAIEmbeddings. This setup facilitates an effective method of extracting and concatenating video frame captions and audio transcriptions, enhancing the AI's contextual understanding and interaction accuracy​​.
